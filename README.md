# 湿地fvc

可复用的 AI Skill 与浏览器本地分析网站源码。支持导入真实 NDVI CSV / 单波段 GeoTIFF，比较 MNDWI、NDWI 和已有水体掩膜方案，以二元像元模型探索植被覆盖度。

**不包含真实观测数据，也不会生成伪造观测值。** 原始文件在浏览器中处理，不上传到分析服务器。

在线工具：[鄱阳湖湿地 FVC 交互分析](https://poyang-wetland-fvc-lab.qhnfasci.chatgpt.site)。该在线版本独立维护；本仓库的源码模板补充了缺失掩膜处理等修正，未自动替换原站点。

本次仅升级 Skill 与源码，**未修改、未重新部署上述公开站点**。

- 同时计算“各方案独立 P5/P95”和“所有方案共用固定端元”两种模式。
- 固定端元默认取所有已载入方案的共同非水体 P5/P95，也可显式指定某一方案作为端元来源；共同区域不足或退化时明确报错，不自动换来源。
- 选择参考方案，对照共享非水体、仅参考方案保留、仅当前方案保留、双方均不保留四类区域。
- 显示各自全域与共同非水体均值、共享区域的候选减参考配对差值；审计另含完整 4×4 像元状态转移矩阵和独有区域统计。
- 固定端元下，同一 NDVI 的共享非水体 FVC 应一致；不同方案全域均值不能直接作为精度对比。

## 本地运行网站

安装符合 `package.json` engines 的 Node.js（例如 24.15.0 或更新的 24.x；本次在 24.22.1 验证），在命令行运行：

```sh
git clone https://github.com/THE-po8/poyang-wetland-fvc.git
cd poyang-wetland-fvc
node skills/poyang-wetland-fvc/scripts/scaffold.mjs ./fvc-site
cd fvc-site
npm ci
npm test
npm run build
```

使用任意静态 HTTP 服务打开 `dist/`。例如已安装 Python 3 时：

```sh
python3 -m http.server 4173 --bind 127.0.0.1 --directory dist
```

在浏览器访问 `http://localhost:4173`。不要直接双击源码 HTML；需要先构建 JavaScript 依赖。

## 模型与数据

1. 导入真实 NDVI，并提供至少一种水体指数或水体掩膜。
2. 排除无效 NDVI、缺少掩膜分类的像元及水体像元。
3. 独立模式按各方案非水体计算 P5/P95；固定模式从明确记录的共同区域或参考方案估计一次，并让所有方案共用。
4. 使用 `FVC = clamp((NDVI - P5) / (P95 - P5), 0, 1)`。分位数在排序位置 `(n - 1) × q` 处线性插值。
5. 水体与无效像元的导出 FVC 留空，不设为 0；端元相同或有效像元不足时停止分析。

CSV 表头结构（没有观测数据行）：

```csv
pixel_id,x,y,ndvi,mndwi,ndwi,water_mask
```

NDVI 必需，MNDWI / NDWI / water_mask 至少提供一项。默认指数阈值为 `> 0`，已有掩膜阈值为 `> 0.5`，可交互调整；阈值不是经验证的通用水体标准。

## 审计与导出

分析后保存同一 run ID 的两份文件：

- `fvc_<run-id>_pixels.csv`：所有方案 × 两种模式的像元结果，含水体阈值、端元、像元状态、共同区域标记、相对参考区域及计算错误。水体/未知/无效像元的 FVC 留空；未知分类的 is_water 也留空而不是标为非水体。
- `fvc_<run-id>_audit.json`：输入文件原始字节 SHA-256、文件大小、字段映射、实际缩放系数、软件版本/构建源码指纹、P5/P95 定义、固定端元来源、有效样本数、排除计数和区域比较。

保留原始输入文件及外部 GIS 对齐/预处理记录。审计 JSON 不包含原始观测值，不能在丢失原始文件后重建数据；文件修改时间不是卫星观测日期。分享审计前检查原始文件名和校验值是否适宜公开。未构建、直接调用 JS 模块时源码指纹为 null，生产构建会注入真实源码 SHA-256。

## 科研边界与验证状态

- 非水体不等于湿地植被。请先完成研究区、植被范围及云/阴影的适当掩膜；不要仅凭工具中的界面名称认定所有结果均为湿地植被。
- GeoTIFF 须先在 GIS 中对齐 CRS、分辨率、范围与像元网格。当前程序只检查尺寸和可用包围盒，不验证完整 CRS/仿射变换等价关系，也不重投影或重采样。
- CSV 预览为输入行顺序，不是地理地图；栅格导出中的 x/y 是列/行索引，不是世界坐标。
- 所有栅格加载到浏览器内存，大影像应先裁剪。无可靠像元面积时不可由计数直接宣称植被面积。
- 完整 Skill 中 31 项模型、审计、生成脚本和 DOM 模拟测试通过，生产构建通过；生成后的独立项目会跳过一项仅适用于 Skill 本体的脚手架测试。DOM 测试使用 jsdom 和模拟 canvas，不等于真实浏览器、真实 GeoTIFF 读取或下载兼容性验证。
- 测试中的数值数组与 CSV 行仅为明确标注的数学用例，不是鄱阳湖观测数据；工具只检查计算和数据结构，不验证输入数据真实性。
- 固定端元来自共同区域不代表其具有生态代表性；当前没有独立参考数据精度评价、误差区间或多时相端元一致化。
- 不保证输出可直接作为论文结论，请独立进行质量控制、精度评估和方法适用性判断。
